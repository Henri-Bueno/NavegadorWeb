# NavegadorWeb

Estrutura inicial de um navegador web simplificado, desenvolvido manualmente com HTML, CSS e TypeScript puro. Nenhuma funcionalidade do navegador foi implementada nesta etapa.

## Compilar o TypeScript

Com o compilador TypeScript (`tsc`) disponível no ambiente, execute:

```sh
cd navegador
tsc -p tsconfig.json
```

O JavaScript compilado será gerado em `navegador/frontend/dist`.
